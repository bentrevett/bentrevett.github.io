Threadwords 🧵

A hybrid of a crossword and a word search. For each clue, find the answer hidden in the grid using, at most, one letter per column.

Answers will always span consecutive columns, from left to right, but will not always start from the first column or end in the last column.

Select tiles to highlight them, once you have the correct number of letters for a clue it will become clickable. Click it to submit your answer.
