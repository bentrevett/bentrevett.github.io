122333 Sudoku 🔢

A Sudoku variant. Fill every cell with a 1, 2 or 3 so that every row, every column, and every block (if there are any) holds exactly one 1, two 2s and three 3s.

If using the Lonely Ones variant (the default) then no two 1s can touch, even diagonally.

Click/tap a cell to cycle it through blank, 1, 2 and 3. Right click a cell to clear it.

Every puzzle has exactly one solution.

Variants

There are several variants:

  • Plain has no blocks.
  • Blocks has regular sized blocks.
  • Jigsaw has irregular sized blocks.
