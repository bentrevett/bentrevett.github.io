122333 Sudoku 🔢

A daily logic puzzle on a six by six grid. Fill every cell with a 1, 2 or 3 so that every row and every column holds exactly one 1, two 2s and three 3s.

Click a cell to cycle it through blank, 1, 2 and 3. The clues you were given are shaded and cannot be changed. A cell turns red when it breaks a rule — too many of a value in a row, column or region.

Every puzzle has exactly one answer, and there is a fresh set of six every day.

Rules

Every puzzle has a name, shown in the heading below: today's is the date, and a random puzzle gets a number. Type a name in to play that exact puzzle, which is also how you set a friend the same one.
