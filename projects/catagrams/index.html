Catagrams 🐈

Every phrase is an anagram of a word plus a few spare letters. Every word belongs to the same category, and so does the solution: an anagram of all the spare letters put together. The category is not given: it is revealed once the solution is in.

Type the word hidden in each phrase. The number after the box is how long it is, and the number after the dots is how many letters it has to spare. Solve one and its spare letters appear, ready to be unscrambled into the solution. Spaces do not count, so OPEN LAD is seven letters, and POLAND takes six of them.

You can try the solution whenever you like, before every phrase is solved if you can see it.
