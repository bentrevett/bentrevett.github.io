Bee Definition 🐝

A daily word puzzle built from the New York Times Spelling Bee. Every answer from one day's Spelling Bee is here, but you are given only its definition and its length.

Type an answer and press Enter. It turns green if you have it and red if you have not. Hint uncovers the first letter, then the second, and so on.

The trick is that every answer is spelled from the same seven letters, and one of those letters appears in every single answer. So each one you get narrows down the letters the rest can possibly be using.

Every puzzle has a name, shown in the heading below: today's is the date, and a random puzzle gets a number. Type a name in to play that exact puzzle, which is also how you set a friend the same one.
